Seatmap Pro Seating for Events

Buyers pick their seats on a Seatmap Pro venue map when they register for an event on your Odoo website.

The sale itself stays in Odoo, from ticket prices to payment. Seatmap Pro supplies the venue drawing and the map the buyer clicks on. Each seat becomes its own cart line and its own attendee, so the seat appears on the order and in the attendee list.

What the module does

  • Loads the venue from Seatmap Pro with one button, one record per seat with its sector, row, and number. Each Seatmap Pro pricing zone is mapped to an Odoo ticket.
  • Shows the seat map where Odoo asks how many tickets the buyer wants. Only seats that are free in Odoo can be selected, and they show the price of the mapped ticket.
  • Holds a seat for the buyer from the click on the map until payment, 15 minutes by default. A scheduled action releases expired holds and removes those seats from abandoned carts.
  • Checks every seat again before payment, and the database refuses a second attendee for the same seat.
  • Works with the standard Odoo cart, checkout, payment providers, and events with several time slots.
  • Keeps the Seatmap Pro organization token on your server. The browser receives only the public key and the event ID.

What you need

  • A Seatmap Pro account. Its settings give you an organization token and a public key.
  • A venue drawn in the Seatmap Pro editor and a published event on that venue.
  • Odoo 20.0 with the Events and eCommerce apps, on your own server or on Odoo.sh. Odoo Online cannot run modules with Python code.

Set up an event

  1. In Events > Configuration > Settings, fill in the organization token and the public key in the Seatmap Pro block.
  2. Open the event, go to the Seatmap Pro tab, enter the ID of the Seatmap Pro event, and select Load venue.
  3. Choose the Odoo ticket sold for each pricing zone.

On the event page, the Register button becomes Choose seats and opens the map.

Limitations

  • Seat selection covers the website. Point of Sale and back-end sales orders do not show the map.
  • The map shows the ticket price. Pricelists and discounts apply in the cart.
  • Standing areas from Seatmap Pro are not imported.
